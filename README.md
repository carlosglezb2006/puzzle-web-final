# Puzzle Pro-Works Corporate Website

This is the official repository for the Puzzle Pro-Works corporate website.

## Tech Stack
- Next.js 15 (App Router)
- Tailwind CSS v4
- React
- Lucide Icons

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Run development server: `npm run dev`

## Deployment

This project is optimized for deployment on Vercel.
- Import the repository
- Click Deploy
